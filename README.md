# 民事法律关系本体 1.0.3

DSH 本地插件包，提供合同审查、法律咨询、类案检索，以及周报和本体关系图。安装时将分发包解压到固定目录，在 DSH 中选择包含 `package.json` 的目录。

| 想做的事 | 入口 |
|---|---|
| 第一次使用，选择接下来要做的事 | 在会话里输入 `/civil`。右侧“民事法律工作台”展示本次指令的结果，可以从这里进入关系图、周报或时间设置 |
| 查看民事本体 | 输入 `/civil-map`。从对象卡查看关系及其方向，点相邻卡继续追溯；另可查随包的方法、法条和企业审查资料 |
| 查看当前委托可用的已批准经验 | 在已经开案的会话输入 `/civil-map case`，打开本案范围内的经验与证据类别摘要 |
| 查看本周变化 | 本人输入 `/civil-digest`，打开本期周报。点来源查看当时的发言或合同摘录 |
| 决定提案是否生效 | 在本人周报页逐项采纳、不采纳或留下详细说明。仅查看详情保持原状态。离线周报供留档 |
| 调整周报时间或查看状态 | `/civil-week` 管理周报时间，`/civil` 查看当前状态 |
| 找回以前审阅过的周报 | 输入 `/civil-digest history`，在清单中选择相应一期 |
| 从原有取舍指令进入审阅 | `/civil-apply`、`/civil-drop`、`/civil-confirm` 和 `/procurement-confirm` 都提供本人审阅入口；打开提案后可查看证据并逐项决定 |
| 查看插件的市场来源 | 输入 `/civil-market` 查看登记结果和后续操作 |
| 实际办理案件 | 直接描述委托。插件提供共用的法律关系和来源查询，开案后按任务提供相应工具 |

### 两张画布从哪里取数

本体图由随包 `civil/` 生成，关系的起点、终点和措辞取自模型文件。周报从本机记录的会话片段、案件材料、纠正和验证记录生成。两张画布使用包内固定的页面和交互代码，模型不能通过这些工具提交 HTML、布局、连线坐标或审批决定。

周报区分三类效力。本案事实留在本案，表达偏好用于约定的交付范围。能改变后案判断的提案要能还原原案纠正、独立相似案、反例及适用边界；本人批准的是看到的提案和证据版本。获得批准后，新案仍需核对自己的事实。
